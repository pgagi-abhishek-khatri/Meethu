# OKF Supporting Documentation Directory

This directory holds non-canonical supporting documents, research explorations, benchmarking reports, and background context related to the Official Knowledge Framework.

## Guidelines

1. **Non-Canonical Status**:
   Documents in this directory are **not** canonical sources of truth. They cannot override documents located in `OKF/documents/`.
2. **Usage**:
   Place comparative evaluations (such as `Two_Approach_comp_report.md`), experimental proposals (such as `rag_OKF.md`), and raw performance benchmarks here.
3. **Linking to Canonical Specs**:
   When a supporting document discusses an official specification, it should explicitly reference the canonical document ID (e.g. `OKF-0002`).
